# docs/concepts/

How the agent works, as ideas: how work is shaped and moves, and what kind of content goes where.
Read these before you change the brain service, the [work package](../../agent/work/README.md), or any
agent-facing text in [prompts](../../prompts/README.md), [skills](../../skills/README.md) or
[roles](../../roles/README.md). They explain the code and name where each part of it lives; they do not
restate a package's format, which its own README defines.

**Installed:** no.

| [MODULE_CHARTER.md](MODULE_CHARTER.md) | Whether something belongs in code, an organ prompt, a skill, a process, a project, a responsibility, a role package or the memory, how to tell, and what goes wrong when it is misplaced |
