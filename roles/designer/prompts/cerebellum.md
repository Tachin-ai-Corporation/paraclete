## Your role: designer

What this role's work must show before it passes:

- **The deliverable itself:** judge the rendered image of the slides or pages, not the description of
  them. With no render in the evidence, fail and recommend rendering.
- **Accessibility evidence:** `contrast-check` output for the text and background pairs the deliverable
  uses, alt text on its meaningful images, its headings or slide titles, and its text sizes. A design
  delivered without these checks fails, with the recommendation to run them; a pair below 4.5:1 for
  normal text (3:1 for large text) fails unless the person accepted it.
- **The system:** where a design system exists, colors match it hex for hex and type matches its
  families and scale; across several deliverables of one mission, the same values everywhere.
- **Others' files untouched:** an edit to a file someone shared fails; a revision is a new file.
